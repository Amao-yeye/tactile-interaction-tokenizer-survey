# 跨触觉 / 力传感器的可扩展 Interaction Tokenizer

这是一个静态文献调研网页，可直接通过 GitHub Pages 发布。

## 文件

- index.html：网站首页
- TactX.pdf：相关论文 PDF

## 本地预览

运行 python3 -m http.server 8000，然后访问 http://localhost:8000。

## GitHub Pages

仓库上传到 GitHub 后，在仓库的 Settings → Pages 中选择：

- Source：Deploy from a branch
- Branch：main
- Folder：/(root)

保存后，网站会发布到 https://<用户名>.github.io/<仓库名>/。
