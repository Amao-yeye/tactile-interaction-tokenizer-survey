Executive summary

先抓住四个结论

现有方法分别解决了“规模”“对齐”“物理锚点”或“跨域迁移”，但尚未完整覆盖这一目标组合。

最准确的研究定位

不是简单训练一个通用 tactile encoder，也不是把所有输入投影到相同维度，而是从大规模、异构、主要不配对的 manipulation trajectories 中学习 sensor-agnostic interaction tokens，并使新传感器通过少量 calibration 与轻量 adapter 接入，尽量不重训共享策略。

01

混合训练 ≠ 自动对齐

FTP-1 证明异构预训练有价值，但 sensor、dataset、robot 和 task 往往耦合，模型可能识别域而非统一物理交互。

02

强跨传感器迁移常依赖 paired contacts

TactX、HTT、CTTP、AnyTouch 的强项来自同步或可比接触监督；这与 FTP-1 的大量非配对聚合数据形成关键矛盾。

03

Force 是好锚点，但不是完整交互状态

UniForce 与 GenForce 提供物理统一尺度，但仅靠力可能丢失接触位置、局部几何、stick/slip、碰撞和 jam 等信息。

04

最有价值的缺口是 adapter-only onboarding

目标应是冻结 shared tokenizer trunk 与 policy，仅训练新传感器的小 adapter；这比“新 sensor finetuning 更快”更清晰。

S

Scale-first：大规模异构预训练

FTP-1、T3。优势是数据规模与多任务，弱点是没有充分显式约束“相同交互跨 sensor 一致”。

A

Alignment-first：跨传感器显式对齐

TactX、HTT、AnyTouch、CTTP。迁移强，但通常需要同步或严格可比的 contact pairs。

P

Physics-first：统一物理中间空间

UniForce、GenForce、TactSpace、ACROSS。用 force、deformation 或 physical stimulus 作为 canonical bridge。

U

Unpaired / extensible：弱配对与域迁移

TactAlign、SITR。分别探索 pseudo-pair latent transport 与模拟传感器变化下的少量校准迁移。

6T3

7AnyTouch统一多种 visuo-tactile sensor 的静态图像与动态视频表示。四传感器 aligned TacQuad；masked modeling + multimodal alignment + matching。学习 sensor-agnostic static/dynamic features 的代表方法。仍主要是视觉式触觉，难直接覆盖 6D wrench。
8CTTP用 paired touch 的 contrastive learning 建立两个 tactile sensor 的共享 embedding。相同物体、相似接触条件下的 GelSlim–Soft Bubble pairs。最小、干净、容易复现的 cross-sensor alignment baseline。传感器数量少且输入机制相近。
9TactSpace将 simulated penetration depth 与真实 capacitance 等异构触觉映射到 physics-enriched shared latent。同一 physical stimulus 的多模态观测；self/cross reconstruction + contrastive alignment。证明 raw-signal 不必相同，物理中间表征可以统一。主要是 tactile sim-to-real，而不是多硬件策略接入。
10GenForce通过统一 marker representation 与 marker-to-marker translation 迁移 force sensing。新 sensor 需要少量 paired calibration；再迁移 force labels。新硬件快速获得 force capability 的重要工程基线。目标是 force calibration / translation，不是统一 control token。
11ACROSS以 3D deformation mesh 作为跨传感器 canonical representation，实现 BioTac → DIGIT 翻译。需要传感器 deformation model 与跨 mesh 映射。说明可解释物理中间空间能重用旧数据。从低维到图像的 signal translation；不直接优化 manipulation token。
12SparshDINO / I-JEPA / MAE 式自监督预训练，获得通用 vision-based tactile features。46 万余张 tactile images；无需任务标签。generic SSL encoder baseline，用于排除“只是预训练更好”的解释。没有显式 cross-sensor physical alignment，也无法直接处理 wrench。

Research gap

目前仍未被完整覆盖的组合

这里的判断是对上述代表工作进行组合比较后的研究定位，不等同于对所有未公开工作的绝对排除。

大规模异构数据FTP-1 · T3
显式跨 sensor 对齐TactX · HTT
物理 canonical spaceUniForce · GenForce
目标组合mostly unpaired + interaction-grounded + adapter-only

Gap 1｜大规模非配对数据上的显式物理对齐

现有规模方法多依赖 shared trunk / action loss；强对齐方法多依赖 paired contacts。缺少利用 state、action 与物理后果，把 FTP-1 式 trajectories 变成跨 sensor 弱配对的方案。

Gap 2｜共享信息与传感器私有信息的解耦

强制 GelSight 与 6D F/T 输出完全相同表示，只能保留信息交集。更合理的是 common interaction tokens + sensor-private tokens + observability/confidence。

Gap 3｜Adapter-only new-sensor onboarding

真正的扩展性应固定 shared trunk 和 downstream policy，只优化新传感器 adapter；而不是从头训练完整 encoder 或再次收集任务示教。

Gap 4｜超越 force 的 action-conditioned interaction grounding

共享 token 不应只重建传感器信号或回归当前力，而应解释在给定机器人状态与动作后，接触如何演化以及为何 nominal dynamics 失效。

Common token 应表达

  • contact / free 与接触强度
  • normal / shear 与整体作用方向
  • stick / slip / collision / jam
  • contact increase / release 等动态阶段
  • 给定动作后的物理 transition residual

Private token 应保留

  • tactile image 的局部接触几何与形状
  • 高密度 array 的局部压力分布
  • 特定传感器独有的高频振动或纹理线索
  • 无法由低维 F/T 观测的空间细节
  • 传感器可观测性与置信度
不要一开始就做离散 codebook：如果共享空间尚未对齐，VQ 很容易把 codebook 分成“GelSight codes / F/T codes / array codes”。先验证 sensor-ID probe 降低、interaction probe 保持，再增加离散化。

普通 random split 无法证明 sensor extensibility。实验单位必须是“传感器/传感器 family 被完整留出”。

第一版最小 baseline 组合

  • Scale：FTP-1 heterogeneous encoders / MTTS
  • Generic SSL：Sparsh 或 T3 encoder
  • Paired alignment upper bound：TactX / CTTP
  • Physics grounding：UniForce-style force target
  • 候选方法：transition-grounded common/private tokens

最重要的消融

  • 只 action loss vs. + physical transition loss
  • 直接共享 latent vs. common/private decomposition
  • 无 metadata vs. location/orientation/type metadata
  • 无 sensor dropout vs. sensor dropout
  • 连续 tokens vs. VQ/FSQ tokens

Recommended positioning

可以逐渐收敛成的论文问题

Can heterogeneous tactile and force observations be mapped into a shared
interaction-token space from large-scale, mostly unpaired manipulation
trajectories, such that a new sensor can be onboarded by adapting only
a lightweight input adapter while keeping the shared policy fixed?

这一研究方向最有辨识度的三个关键词是：unpaired physical alignment、common/private token decomposition、adapter-only sensor onboarding。

Tokenizer primer

Tokenizer 是什么：原理、经典论文与主流范式

Tokenizer 不只存在于大语言模型，也不必然等于“离散词表”。更一般地，它定义了原始观测如何被切分、压缩、编码，并以有限长度的 token 序列交给后续模型。

一句话定义

Tokenizer 是原始数据与序列模型之间的接口协议。它同时回答四个问题：什么算一个基本单元、输出多少个单元、每个单元是连续向量还是离散编号，以及这些单元通过什么训练目标获得语义。

  → optional bottleneck Q

Token

模型处理的基本单元

可以是词片段、图像 patch、时间窗口、学习得到的 latent slot，也可以是 codebook 中的整数编号。现代多模态模型中，token 往往只是一个 d 维连续向量。

Tokenizer

生成 token 的映射与规则

不仅包括 encoder，还包括切分粒度、序列长度、位置与时间编码、可选量化，以及决定 token 应保留什么信息的训练目标。

Encoder

抽取内容，但未必定义接口

Encoder 将输入变成 feature。只有当这些 feature 被组织成稳定、可消费的序列协议时，才形成完整 tokenizer。一个 CNN feature map 本身不自动等于通用 token space。

Codebook

离散 tokenizer 的“词典”

VQ 类方法维护有限个向量原型，将连续 latent 替换为最近的 code。它利于压缩、生成和发现重复 primitive，但会带来 codebook collapse 与量化误差。

一个完整 tokenizer 通常包含五个阶段

01

原始输入

文本、RGB、触觉图像、taxel array、6D wrench 或多速率时间序列。

x ∈ raw sensor space
02

切分 / 单元化

字符合并、固定 patch、taxel 点、滑动时间窗，或按接触区域划分。

S(x) = {u₁,…,uₙ}
03

编码 / 投影

将不同形态和量纲统一到共享 hidden dimension，并注入位置、方向和时间信息。

hᵢ = E(uᵢ, metadata)
04

压缩 / 量化

可保持连续，也可用 query resampler、VQ、FSQ 或多级 RVQ 压缩。

zᵢ = Q(hᵢ) or hᵢ
05

序列接口

输出固定或可变长度 token 序列，供 Transformer、world model 或控制策略消费。

Z ∈ ℝᴷˣᵈ or {1,…,V}ᴷ
最常见的概念误区：token 不一定离散。ViT 的 patch embeddings、Perceiver 的 latent slots、Flamingo 的 Perceiver Resampler 和 BLIP-2 的 query tokens 都是连续 token；VQ-VAE、VQGAN 与 FSQ 才显式产生离散 codes。
Mainstream families

六类主流 tokenizer 方法

这些方法并不互斥。实际系统常采用“固定 patch + learned encoder + query compression + optional quantization”的组合。

01 · SUBWORD

规则 / 统计式子词切分

BPE 迭代合并高频符号对；WordPiece 采用 longest-match 与词表目标；Unigram LM 从候选子词中概率化选择。优点是可逆、成熟、适合离散文本，通常不直接用于连续传感器。

characters → frequent merges → token IDs
代表：BPE · WordPiece · Unigram · SentencePiece
02 · PATCH / WINDOW

固定空间或时间切分

ViT 将图像切成规则 patch 后线性投影；时序传感器可按固定窗口或 stride 切分。结构简单、吞吐高，但 token 边界不一定对应真实语义或接触事件。

zᵢ = W · vec(patchᵢ) + pᵢ
触觉：image patches · taxel groups · force windows
03 · CONTINUOUS

连续 encoder / projector token

CNN、ViT、TCN 或 MLP 直接输出 ℝᵈ tokens。训练稳定、保真度高，适合控制与跨传感器 adapter；缺点是缺少天然词表和符号可解释性。

Z = Projector(Encoder(x))
无最近邻量化 · 端到端可微
04 · QUERY / SLOT

学习查询与固定长度 resampling

一组 learned queries 对任意长度输入做 cross-attention，压成固定 K 个 slots。Perceiver、Flamingo Resampler、Q-Former 和 TokenLearner 都属于这一大类。

Z = CrossAttention(Q_learned, H_input)
适合：异构长度 · 多传感器 · 固定上下文预算
05 · DISCRETE

VQ / FSQ / RVQ 离散量化

VQ 用最近邻 codebook；FSQ 对少量 latent 维度逐维量化；RVQ 逐级编码残差。适合自回归生成、压缩和 primitive discovery，但应监控 code 利用率与量化损失。

VQ: k = argminⱼ ‖h − eⱼ‖²
FSQ: zq = round(bound(z))
06 · GROUNDED

任务 / 物理结果驱动 token

不以重建原始像素为唯一目标，而让 token 预测语言、动作、未来观测、力或状态转移。对触觉而言，这类 objective 更有机会学习跨传感器共享的 interaction semantics。

maximize I(z; physical outcome | state, action)
而非只 maximize I(z; raw pixels)
连续 token

保留信息多、训练容易、适合第一版跨传感器统一接口；但序列可能较长，缺少离散 primitive。

离散 token

便于压缩、生成与统计 code 使用；但共享空间尚未对齐时，codebook 很容易编码 sensor identity。

Query token

固定输出长度并兼容可变输入，尤其适合 image、array 与 wrench 混合；语义取决于 query 的训练目标。

Classic papers

理解 tokenizer 最值得读的经典论文

从文本的统计切分，到视觉 patch、学习式离散 codebook、在线 teacher tokenizer、固定长度 latent queries，再到机器人动作序列压缩，构成了今天多模态 tokenizer 的主要技术谱系。

论文年份 / 领域核心贡献对触觉 tokenizer 的启发主来源
Japanese and Korean Voice Search2012 · NLP / Speech早期 WordPiece 路线：以子词词表缓解开放词汇问题，后来被 BERT 等模型广泛采用。说明 tokenizer 首先是“可复用词表 + 稳定分解规则”，而不只是 encoder。DOI ↗
Neural Machine Translation of Rare Words with Subword Units2016 · NLP将 BPE 引入神经机器翻译，通过迭代合并高频符号对构建子词 vocabulary。最经典的“由数据频率发现复用 primitive”范式。ACL ↗
Neural Discrete Representation Learning2017 · Representation提出 VQ-VAE：encoder 输出经最近邻 codebook 量化，形成可学习离散 latent。触觉离散 codebook、contact primitive 与生成式 world model 的基础。Paper ↗
Subword Regularization2018 · NLP提出 Unigram LM segmentation，并在训练时采样多种子词切分以提高鲁棒性。启发“同一触觉轨迹可以有多尺度、多分辨率 tokenization”，而不是固定唯一切分。ACL ↗
SentencePiece2018 · NLP从原始文本直接训练语言无关的 BPE / Unigram tokenizer，并提供可逆工程实现。强调 tokenizer 既是算法也是数据规范、归一化和部署工具链。ACL ↗
An Image is Worth 16×16 Words2021 · VisionViT 将规则图像 patch 线性投影为连续 token，证明 Transformer 不要求离散输入。触觉图像最直接的 patch-token baseline；也适合规则 taxel grid。ICLR ↗
Perceiver: General Perception with Iterative Attention2021 · Multimodal用非对称 cross-attention 把高维、任意结构输入蒸馏到紧凑 latent array。非常适合将不同长度、不同拓扑的触觉/力输入统一成固定数量 tokens。Paper ↗
TokenLearner2021 · Vision / Video学习少量自适应空间—时间 tokens，替代密集规则 patch，降低后续 attention 成本。启发从大面积 tactile map 中动态提取接触区域与关键变化。NeurIPS ↗
Taming Transformers / VQGAN2021 · Visual generation用感知与对抗损失训练高质量离散视觉 codebook，再用 Transformer 建模 code 序列。说明“重建质量好的离散 token”通常需要超越像素 MSE 的目标。Project ↗
BEiT: BERT Pre-Training of Image Transformers2022 · Vision SSL先用离散 image tokenizer 生成视觉词表，再遮挡图像 patches，让 Transformer 恢复对应 visual token。提供“masked tactile patch → discrete teacher target”的直接模板，也揭示 tokenizer 质量会决定预训练目标质量。Paper ↗
iBOT: Image BERT Pre-Training with Online Tokenizer2022 · Vision SSL以 EMA teacher 作为在线 tokenizer，对 masked patch tokens 和 global token 同时做 self-distillation，避免先单独训练固定 dVAE tokenizer。对触觉尤其重要：tokenizer 可以和表示目标联合演化，不必先冻结一个只会重建像素的 codebook。Paper ↗
Flamingo2022 · Vision-languagePerceiver Resampler 将可变数量视觉 feature 压成固定数量连续 visual tokens。与 sensor-extensible tactile interface 的结构最相似：输入长度可变，输出预算固定。Paper ↗
BLIP-22023 · Vision-languageQ-Former 用 learned queries 从冻结视觉 encoder 中抽取与文本最相关的固定长度表示。说明 token 的语义由下游对齐目标决定；同样结构可改为 force / dynamics queries。Paper ↗
Finite Scalar Quantization2024 · Discrete representation以少量维度的有限标量量化替代 VQ，形成隐式 codebook，并避免复杂 codebook 维护。适合在连续触觉共享空间稳定后，作为低维护成本的离散化方案。ICLR ↗
FAST: Efficient Action Tokenization2025 · Robotics先对连续 action chunk 做 DCT，再量化并按低频优先展开，最后用 BPE 压缩成离散动作 tokens。说明物理时序不必逐时刻独立分箱；触觉/力历史也可先进入频域或事件域，再发现可复用的动态 primitives。Official ↗
Design guide

触觉场景中怎样选择 tokenizer

目标优先方案原因主要风险 / 必做诊断
先把单一触觉图像接入 TransformerViT patch tokens 或 CNN feature tokens实现最简单，保留空间结构，方便复用视觉 backbone。强 crop / color augmentation 可能破坏真实形变与力信息。
混合 image、array、wrench 等异构输入Family-specific stems + Perceiver/Q-Former 式 learned queries允许输入长度和拓扑不同，同时输出固定 K×d 接口。检查 token 是否泄露 sensor ID，metadata 是否被正确使用。
发现重复接触 primitive 或做自回归 world model先学连续共享空间，再加 VQ / FSQ / RVQ离散 token 便于生成、统计和组合。监控 code utilization、perplexity、dead codes 与量化误差。
换新传感器时只训练小 adapter连续 common/private tokens + geometry/type/time metadata比强行共享离散词表更易适应未见过的信号尺度和布局。必须做 leave-one-sensor-out 与 frozen-policy transfer。
保留 slip、impact、force trend 等动态信息多速率 temporal windows + event/query tokens单帧无法判断加载/卸载、滑移方向和接触转移。检查时间同步、延迟、滤波与采样频率差异。
让 token 表示物理交互而非传感器外观Force/contact/transition-grounded auxiliary objectives物理结果是跨 sensor 更稳定的共同变量。避免只对齐信息交集；保留 sensor-private token。

一个好的 tactile tokenizer 应该满足

  • 信息充分：能预测力、接触模式、滑移或后续状态转移。
  • 紧凑：token 数量和计算量受控，而不是复制完整 feature map。
  • 传感器不变：common tokens 难以预测 sensor identity。
  • 可组合：多个传感器同时输入时能够融合，而非互相覆盖。
  • 可扩展：新 sensor 只需少量校准与小 adapter。

最常见的失败模式

  • 把“线性投影到 hidden size”误当成已学到共享语义。
  • VQ codebook 按传感器类型分区，而不是按 interaction primitive 分区。
  • 强制所有传感器完全一致，丢掉高分辨率触觉独有的几何信息。
  • 只优化重建，token 对控制和状态转移没有增量价值。
  • 随机划分训练/测试，无法证明新传感器扩展性。
Tactile simulation

触觉仿真平台：链接、输出与适用场景

“触觉仿真”可能只模拟接触力，也可能一直模拟到弹性体形变、marker motion 与 RGB 光学成像。选平台前必须先确定需要哪一层输出，以及是否优先速度、物理精度、可微性或 sim-to-real。

一个完整视触觉仿真栈包含哪些层？

Layer 1

机器人与物体动力学

关节、控制器、刚体或可变形物体运动，通常由 MuJoCo、PhysX、PyBullet、SAPIEN 或专用 solver 处理。

Layer 2

接触与摩擦

接触点、penetration、normal/shear force、摩擦、stick/slip 与碰撞稳定性。

Layer 3

弹性体形变

Gel pad、skin 或 taxel substrate 的位移、应力与表面形状；可用近似模型、FEM、MPM 或 IPC。

Layer 4

光学与 marker

表面法向到 RGB 的映射、阴影、光照、marker displacement 与相机成像。

Layer 5

传感器电子学

噪声、饱和、量化、漂移、延迟、滤波、坐标系与不同采样频率。

比较原则：只输出 contact force 的通用引擎，不能与生成真实 GelSight RGB 的平台按“图像保真度”直接比较；高保真 FEM 也不应只按每秒环境步数与近似渲染器比较。
R

快速光学 / 几何近似

TACTO、Taxim、FOTS、Tacchi。适合快速生成 tactile RGB/depth/marker 信号、做感知预训练和早期 sim-to-real；通常不完整模拟软体应力与复杂摩擦。

G

GPU 大规模策略学习

TacSL、Taccel、ETac、Tactile Genesis。强调并行环境、可配置 tactile fields 和在线 RL/IL；UniVTAC 则进一步提供统一数据生成与 benchmark。

∂

可微 / 高保真物理

DiffRedMax、DiffTactile、TacIPC、TaCauchy、HydroShear。适合系统辨识、材料参数优化、gradient-based control，以及 stress / traction / deformation / shear ground truth；通常配置更复杂。

F

通用 contact / force 底座

MuJoCo、Isaac Lab、ManiSkill/SAPIEN、Genesis World、Gazebo。适合 6D wrench、joint torque、contact force 或自定义 taxel 信号；光学与软体保真度依平台而异。

Selection guide

按研究目标快速选平台

需要最快开始

TACTO / Taxim / FOTS

已有刚体 simulator，只想补 tactile RGB 或 marker motion；优先采用轻量、可插拔的渲染模型。

需要 GPU 大规模 RL

TacSL / Taccel / Tactile Genesis

大量并行 contact rollouts、在线策略学习或 sensor-layout ablation 是第一优先级；ETac 适合学习式大面积形变。

已使用 Isaac Lab

TacSL / TacEx / UniVTAC / TaCauchy

前两者偏 sensor integration；UniVTAC 提供完整数据与 benchmark 流程；TaCauchy 提供更严格的 FEM stress/traction ground truth。

需要梯度

DiffRedMax / DiffTactile

做材料系统辨识、参数优化、trajectory optimization 或 differentiable policy learning。

需要高保真形变基准

TacIPC / DiffTactile / TaCauchy

更关心稳定 FEM、材料、摩擦、stress/traction 和软体接触，而不是最高环境吞吐。

仿真怎样帮助训练可扩展 tactile tokenizer

仿真的最大价值不是替代真实数据，而是提供同一物理 interaction 的多种 sensor rendering 和完整 canonical labels，从而制造真实世界难以获得的跨传感器配对。

建议在仿真中记录的 canonical labels

  • 每个接触点的位置、法向、切向速度与接触对象 ID。
  • normal / shear force field、合成 6D wrench 与坐标变换。
  • gel / skin deformation、penetration depth 与 marker displacement。
  • stick、slip、impact、release、jam 等接触阶段。
  • 动作前后的 robot/object state transition。

避免“仿真捷径”的训练设计

  • 随机化光照、marker、材料、噪声、延迟、饱和和采样率。
  • 不要只用像素相同定义 positive pair；以 canonical physics 为对齐依据。
  • 完整留出一个 renderer 或 sensor family 做测试。
  • 同时保留大量未配对 trajectory，避免模型依赖同步配对。
  • 用少量真实 paired calibration 作为 scale 与坐标锚点。
实现时最容易忽略的细节：不同引擎对 contact force 的符号、参考坐标系、作用点、时间积分、solver impulse 与滤波定义并不一致。公开数据前应同时保存原始 impulse、换算后的 force、时间步长、sensor frame 和变换链。
