Executive summary

先抓住四个结论

现有方法分别解决了“规模”“对齐”“物理锚点”或“跨域迁移”，但还没有完整覆盖你的目标组合。

最准确的研究定位

不是简单训练一个通用 tactile encoder，也不是把所有输入投影到相同维度，而是从大规模、异构、主要不配对的 manipulation trajectories 中学习 sensor-agnostic interaction tokens，并使新传感器通过少量 calibration 与轻量 adapter 接入，尽量不重训共享策略。

01

混合训练 ≠ 自动对齐

FTP-1 证明异构预训练有价值，但 sensor、dataset、robot 和 task 往往耦合，模型可能识别域而非统一物理交互。

02

强跨传感器迁移常依赖 paired contacts

TactX、HTT、CTTP、AnyTouch 的强项来自同步或可比接触监督；这与 FTP-1 的大量非配对聚合数据形成关键矛盾。

03

Force 是好锚点，但不是完整交互状态

UniForce 与 GenForce 提供物理统一尺度，但仅靠力可能丢失接触位置、局部几何、stick/slip、碰撞和 jam 等信息。

04

最有价值的缺口是 adapter-only onboarding

目标应是冻结 shared tokenizer trunk 与 policy，仅训练新传感器的小 adapter；这比“新 sensor finetuning 更快”更清晰。

S

Scale-first：大规模异构预训练

FTP-1、T3。优势是数据规模与多任务，弱点是没有充分显式约束“相同交互跨 sensor 一致”。

A

Alignment-first：跨传感器显式对齐

TactX、HTT、AnyTouch、CTTP。迁移强，但通常需要同步或严格可比的 contact pairs。

P

Physics-first：统一物理中间空间

UniForce、GenForce、TactSpace、ACROSS。用 force、deformation 或 physical stimulus 作为 canonical bridge。

U

Unpaired / extensible：弱配对与域迁移

TactAlign、SITR。分别探索 pseudo-pair latent transport 与模拟传感器变化下的少量校准迁移。

6T3
unaligned data13 sensors
sensor-specific encoders、shared Transformer trunk、task-specific decoders；FoTa 超过 300 万数据点。跨公开数据集聚合，不要求同步 sensor pairs。FTP-1 image encoder 与 shared-trunk 路线的重要前身。主要针对 camera-based tactile；新 sensor 往往仍需少量微调。
7AnyTouch统一多种 visuo-tactile sensor 的静态图像与动态视频表示。四传感器 aligned TacQuad；masked modeling + multimodal alignment + matching。学习 sensor-agnostic static/dynamic features 的代表方法。仍主要是视觉式触觉，难直接覆盖 6D wrench。
8CTTP用 paired touch 的 contrastive learning 建立两个 tactile sensor 的共享 embedding。相同物体、相似接触条件下的 GelSlim–Soft Bubble pairs。最小、干净、容易复现的 cross-sensor alignment baseline。传感器数量少且输入机制相近。
9TactSpace将 simulated penetration depth 与真实 capacitance 等异构触觉映射到 physics-enriched shared latent。同一 physical stimulus 的多模态观测；self/cross reconstruction + contrastive alignment。证明 raw-signal 不必相同，物理中间表征可以统一。主要是 tactile sim-to-real，而不是多硬件策略接入。
10GenForce通过统一 marker representation 与 marker-to-marker translation 迁移 force sensing。新 sensor 需要少量 paired calibration；再迁移 force labels。新硬件快速获得 force capability 的重要工程基线。目标是 force calibration / translation，不是统一 control token。
11ACROSS以 3D deformation mesh 作为跨传感器 canonical representation，实现 BioTac → DIGIT 翻译。需要传感器 deformation model 与跨 mesh 映射。说明可解释物理中间空间能重用旧数据。从低维到图像的 signal translation；不直接优化 manipulation token。
12SparshDINO / I-JEPA / MAE 式自监督预训练，获得通用 vision-based tactile features。46 万余张 tactile images；无需任务标签。generic SSL encoder baseline，用于排除“只是预训练更好”的解释。没有显式 cross-sensor physical alignment，也无法直接处理 wrench。

Research gap

目前仍未被完整覆盖的组合

这里的判断是对上述代表工作进行组合比较后的研究定位，不等同于对所有未公开工作的绝对排除。

大规模异构数据FTP-1 · T3
显式跨 sensor 对齐TactX · HTT
物理 canonical spaceUniForce · GenForce
你的目标mostly unpaired + interaction-grounded + adapter-only

Gap 1｜大规模非配对数据上的显式物理对齐

现有规模方法多依赖 shared trunk / action loss；强对齐方法多依赖 paired contacts。缺少利用 state、action 与物理后果，把 FTP-1 式 trajectories 变成跨 sensor 弱配对的方案。

Gap 2｜共享信息与传感器私有信息的解耦

强制 GelSight 与 6D F/T 输出完全相同表示，只能保留信息交集。更合理的是 common interaction tokens + sensor-private tokens + observability/confidence。

Gap 3｜Adapter-only new-sensor onboarding

真正的扩展性应固定 shared trunk 和 downstream policy，只优化新传感器 adapter；而不是从头训练完整 encoder 或再次收集任务示教。

Gap 4｜超越 force 的 action-conditioned interaction grounding

共享 token 不应只重建传感器信号或回归当前力，而应解释在给定机器人状态与动作后，接触如何演化以及为何 nominal dynamics 失效。

Common token 应表达

  • contact / free 与接触强度
  • normal / shear 与整体作用方向
  • stick / slip / collision / jam
  • contact increase / release 等动态阶段
  • 给定动作后的物理 transition residual

Private token 应保留

  • tactile image 的局部接触几何与形状
  • 高密度 array 的局部压力分布
  • 特定传感器独有的高频振动或纹理线索
  • 无法由低维 F/T 观测的空间细节
  • 传感器可观测性与置信度
不要一开始就做离散 codebook：如果共享空间尚未对齐，VQ 很容易把 codebook 分成“GelSight codes / F/T codes / array codes”。先验证 sensor-ID probe 降低、interaction probe 保持，再增加离散化。
Evaluation

怎样证明“新传感器可扩展”

普通 random split 无法证明 sensor extensibility。实验单位必须是“传感器/传感器 family 被完整留出”。

第一版最小 baseline 组合

  • Scale：FTP-1 heterogeneous encoders / MTTS
  • Generic SSL：Sparsh 或 T3 encoder
  • Paired alignment upper bound：TactX / CTTP
  • Physics grounding：UniForce-style force target
  • 你的方法：transition-grounded common/private tokens

最重要的消融

  • 只 action loss vs. + physical transition loss
  • 直接共享 latent vs. common/private decomposition
  • 无 metadata vs. location/orientation/type metadata
  • 无 sensor dropout vs. sensor dropout
  • 连续 tokens vs. VQ/FSQ tokens

Supplementary reading

五篇补充阅读

不一定是核心竞争方法，但会直接影响模型细节或评测设计。

SITR: Sensor-Invariant Tactile Representation

模拟多种 optical sensor designs，以 minimal calibration 实现新视觉式触觉传感器的 zero-shot transfer；适合参考“同 family 新设备”的 onboarding。

TacVerse

7 种 VBTS、106,800 images，系统评估 within-sensor、zero-shot 与 few-shot sensor shift；适合做 controlled cross-sensor benchmark。

Sparsh-X

在 Digit 360 上融合 image、audio、motion、pressure；说明同一硬件内多种触觉模态如何形成互补的 contact embedding。

exUMI / Tactile Prediction Pretraining

以 action-aware future tactile prediction 学 contact dynamics；适合设计 interaction-grounded temporal objective。

UniT

用 VQ-VAE / VQGAN 学 compact tactile latent；适合作为 reconstruction-grounded tokenizer 与离散化 baseline。

Recommended positioning

可以逐渐收敛成的论文问题

Can heterogeneous tactile and force observations be mapped into a shared
interaction-token space from large-scale, mostly unpaired manipulation
trajectories, such that a new sensor can be onboarded by adapting only
a lightweight input adapter while keeping the shared policy fixed?
